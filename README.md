# 🚀 Getting Started

## Clone Repository

```bash
git clone https://github.com/akash-shit/portfolio.git
```

---

## Install Dependencies

```bash
npm install
```

---

## Start Development Server

```bash
npm run dev
```

---

## Build for Production

```bash
npm run build
```

---

## Preview Production Build

```bash
npm run preview
```
